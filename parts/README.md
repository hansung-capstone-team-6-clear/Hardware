# parts/ — 부품 하나씩 단독 테스트

부품을 **하나씩** 연결하고, 짧은 테스트 스크립트로 동작을 확인하고, 결과를 기록하는 곳이다.
한꺼번에 다 연결하면 무엇이 문제인지 알 수 없다.

## 순서와 완료 기준

| 순서 | 폴더 | 부품 | 완료 기준 | 기한 |
| --- | --- | --- | --- | --- |
| 1 | `audio/` | ICS-43434 마이크, MAX98357A 앰프, 스피커 | 5초 녹음 → 재생이 들린다 | 10/18 |
| 2 | `button/` | PTT 버튼 | 누름·뗌이 각각 한 번씩 출력된다 | 10/18 |
| 3 | `led/` | WS2812B 24구 링 | 상태 색 6가지가 바뀐다 | 10/31 |
| 4 | `lcd/` | ST7789 1.69" | 표정 이미지와 한글 문구가 보인다 | 10/31 |

오디오가 1순위인 이유: 마이크와 앰프가 I2S를 같이 써서 설정이 가장 까다롭고, 안 되면 대안(USB)을 빨리 정해야 한다.

## 각 폴더에 남길 것

1. `README.md` — 배선, 설정, 테스트 방법, 완료 기준, **결과 기록** (날짜·결과·사진 링크·막힌 점)
2. `test_<부품>.py` — README의 테스트 코드를 저장해 둔 것 (부품만 단독으로 실행)
3. 배선 사진 (선택) — `wiring.jpg`

## app/로 옮기기

테스트가 통과하면, 그 코드를 함수로 정리해서 `../app/devices/<부품>.py`에 옮긴다.
`app/devices/`의 함수 이름은 이미 정해져 있다 (`../app/devices/README.md`).

## 전체 핀맵

| 부품 | 신호 | GPIO (물리 핀) | 전원 |
| --- | --- | --- | --- |
| ICS-43434 마이크 | BCLK / LRCLK / DATA IN | GPIO18 (12) / GPIO19 (35) / GPIO20 (38) | 3.3V (1), GND (9) |
| MAX98357A 앰프 | BCLK / LRCLK / DATA OUT | GPIO18 (12) / GPIO19 (35) / GPIO21 (40) | 5V (2), GND (6) |
| ST7789 LCD | SCLK / MOSI / CS / DC / RST | GPIO11 (23) / GPIO10 (19) / GPIO8 (24) / GPIO24 (18) / GPIO25 (22) | 3.3V (17), GND (14) |
| WS2812B LED 링 | DIN | GPIO12 (32) | 5V (4), GND (20) |
| PTT 버튼 | 입력 (내부 풀업) | GPIO17 (11) | GND (아무 GND 핀) |

- 핀 번호는 이 표만 보고 연결한다. Notion에 있던 배선 그림은 핀 라벨이 실제와 달라서 쓰지 않는다.
- 서보 모터(SG90)는 2차 범위라 연결하지 않는다 (LED와 PWM 충돌 가능, 5V 전원 부담).
- 전원을 끈 상태에서 배선한다.
